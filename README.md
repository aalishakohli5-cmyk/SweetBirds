# 🐦 SweetBirds

SweetBirds is a simple bird-awareness website featuring rare, extinct and beautiful songbirds. Each card contains a bird’s photograph, conservation status, short description and recorded sound.

## Featured Birds

- Regent Honeyeater
- Bachman’s Warbler
- White-rumped Shama

## Built With

- HTML
- CSS
- HTML audio controls
