# 🐦 SweetBirds

BirdHop is a simple HTML webpage created for a course assignment. Visitors can click different bird emojis to hop to their information sections.

## Features

- Clickable bird navigation
- Parrot, owl and eagle facts
- Colorful HTML design
- Emoji tree
- “Hop back to the top” links
- No CSS or JavaScript

## Built With

- HTML only

## How to Open

1. Download or clone this repository.
2. Open `index.html` in a web browser.
